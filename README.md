# 目标流 GoalFlow

> 把一整年画成一张图，让"当下最重要"自己发光。

一个**纯本地、双击即用**的可视化时间管理工具（`index.html` + `assets/`，无构建）。没有账号，没有云端，没有订阅——你的目标、客户的跟进、想了三年没动的书，数据全在你自己电脑里。

作者：史贵昌（十年企业数字化咨询顾问）

---

## 它解决什么问题

待办清单越列越长，每天睁眼先看一眼，然后很自然地——先做最简单的那几条。真正重要的那件事，"等一下再做"。一天结束，忙得脚不沾地，回头一看，忙而无功。

四象限的道理每个职场人都懂，可"重要不紧急"那一类，从来没被真正安排进时间表。

**目标流不是来教你"要事第一"的——它是来让你"看见"的。看见，才有选择。**

## 核心功能

**1. 目标粘进去，自动画成一条桑基河**
整段年度目标粘贴进来，自动解析成目标树，画成桑基图：带子越宽越重要，颜色越暖越紧急。你的精力错配，一眼看见。

**2. "当下最重要"算法替你定，还告诉你为什么**
按「重要度×10 + 期限临近加权」从整棵目标树拽出唯一那件事，放在页面最顶上的英雄卡里——已逾期？期限临近？还是长期主线该提前投入了？每天不用再"纠结先做哪个"。

**3. 时间像地图一样缩放：年 → 月 → 周 → 日**
年度总览看 12 个月精力扎堆在哪，每周看 7 天节奏，每日看 7 个时段。每次缩放，精力比例尺、流图、四象限、聚焦清单全部联动切换。"本周最重要"和"今日最重要"不是同一件事。

**4. 四象限不用填表，拖一下就好**
把任务卡拖进对应象限，重要/紧急分值自动归位，流图条带、英雄卡、聚焦清单实时重新计算。

**5. SMART 体检 + 对话式拆解**
"提升销售能力"这种目标，体检面板逐项亮灯：不具体、不可衡量、无限期。点「对话拆解」，助手一项项追问，把模糊愿望整成有指标、有期限的行动，一键拆成子任务。

**6. 执行闭环（v4.3）**
- **Top3** + **Backlog 泳道**（上周未完成 / 下月预告，不污染 Top3）
- **树形内联维护**、**预估/实计分钟**与日视图「可做完性」
- **周回顾**自动预填（完成叶子、金线动静、核心 vs 救火计数）
- **📅 ICS** 导出带期限叶子；**JSON 备份 v6**（含时长字段）
- 桑基/关系图、V/E 矩阵、例行展开、rollup 见 `docs/PROGRESS-ROLLUP.md`

首次打开为**空状态**，需自行粘贴目标；或在下拉框中选 **10 个示例主题**之一后点「载入示例」。不再自动灌入示例数据。

## 快速开始

**方式一：在线用**（无需安装，推荐）
浏览器打开：**https://guichangcoder.github.io/goalflow/** —— 数据存在本地浏览器，打开即用。

**方式二：下载到本地**
克隆或下载整个仓库，双击 `index.html`（须保留 `assets/` 目录）。离线可用；字体 CDN 可选（无网时回退系统字体）。

## 数据与隐私

- 所有目标数据仅存储于你浏览器的 localStorage，**不上传任何服务器**
- LLM 对话功能使用你自己的 DeepSeek API Key（页面内填写，仅存于本机浏览器）
- 无账号体系、无遥测、无第三方追踪脚本

> 提示：localStorage 随浏览器缓存清理而丢失。请使用顶栏 **💾 备份** 定期导出 `goalflow-backup-*.json`，需要时用 **📂 恢复**。

## 目录结构

```
├── index.html              # 页面壳（HTML + 外链资源）
├── assets/
│   ├── css/
│   │   ├── main.css        # 样式入口
│   │   ├── tokens.css      # 设计令牌
│   │   └── components/     # 按钮、布局、业务模块样式
│   └── js/
│       ├── gf-tokens.js    # 设计令牌（与 CSS 同步）
│       ├── gf-demos.js     # 10 个示例目标主题
│       └── app.js          # 应用逻辑
├── docs/DESIGN-SYSTEM.md   # 组件与 class 约定
└── README.md
```

> **使用方式**：克隆或下载整个仓库后打开 `index.html`（需与 `assets/` 同目录）。仅需一个文件时运行 `node scripts/inline-bundle.mjs`，使用 `dist/index-standalone.html`。
