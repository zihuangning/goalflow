# 用例集自检（≥80 分再交付）

每项 20 分，满分 100。

| 项 | 通过标准 |
|----|----------|
| 四类场景 | 正常 / 异常 / 边界 / 数据安全 均有 ≥1 条（极小功能可合并异常与数据安全） |
| 格式与追溯 | 模板表格 + 编号合规；**需求依据** / **依据置信度** 齐全；待确认预期不写死；回复列出待确认条数 |
| 可执行 | 步骤可在本机打开 `index.html` 或跑 `node scripts/...` 完成 |
| 与测试体系一致 | 自动化建议落在 unit/flow/smoke/verify/manual；不编造不存在的 API/框架 |
| 边界 | 至少 2 条边界（空集合、时长 min/max、跨天、容量上下限等） |

未达标：补场景后重出，并说明补了哪类。
