根目录是运行时编排点：
- `index.html` 作为唯一页面入口，按 `<script>` / `<link>` 顺序加载 `assets/css/main.css`、`assets/js/gf-tokens.js`、`assets/js/app.js` 并组装左轨 + 侧栏 + 主内容三区域 DOM；`#today` / `#plan` / `#insights` / `#ai` 四个 `<section class="view">` 由原生 JS 根据 `data-view` 属性与 `localStorage.goalflow.theme|mode` 动态切换。
- `assets/` 子模块承载全部业务——样式设计令牌与组件类、示例数据、核心交互逻辑，被 index.html 直接依赖。
- `demos/` 子模块复用同一套 `assets/css/components/*` 组件样式与设计令牌，仅替换外层 HTML 骨架，以十种第三方产品视觉语言呈现相同内核；其 `index.html` 通过相对链接回跳至 `../index.html` 的实际功能页面，形成“外壳 demo → 实质 shell”的双向导航。
- 两个子模块之间不存在运行时耦合：demo 只消费 assets 提供的 CSS 类名，不引用 `app.js`，实现外观与行为分离。
