资源按 CSS/JS 两套平级目录组织，均无构建工具依赖，直接在 HTML `<head>` 与 `<body>` 末尾顺序加载。

- 样式入口 `assets/css/main.css` 通过一组 `@import` 声明以依赖顺序引入 tokens、base、各 component 以及 mobile；tokens 实际由同步加载的 CSS 文件提供（见注释），确保主题变量在 base 之前可用。
- `base.css` 定义 CSS 自定义属性（--font-ui, --ink, --body-bg 等），组件样式仅消费这些语义变量，形成「tokens → base → components」的内部分层。
- JS 采用全局 IIFE 模式暴露模块：`gf-tokens.js` 在页面启动时写入 `GoalFlowTheme`，并通过 `<html data-theme data-mode>` 驱动双轴主题切换；`gf-demos.js` 暴露 `GoalFlowDemos.list` / `get` 供 UI 载入预设场景；`app.js` 作为应用主体，从 `window.GoalFlowTheme` 读取 PALETTE_UR、CAT、COLORS、STORAGE、BTN 等配置，再挂载到全局 state 并使用 localStorage 持久化节点/工作流/元信息。组件之间无模块系统导入，所有状态与 API 通过顶层对象隐式耦合。
